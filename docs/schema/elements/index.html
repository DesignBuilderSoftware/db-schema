    Generated from the DesignBuilder.xsd bundled with the dsbxml package (213 element names, 3316 declarations). Each section lists an element's attributes, its child elements and the elements it appears under. Where the schema declares the same element name with different content in different places, each distinct form is shown as a numbered variant.

    Occurs is minOccurs..maxOccurs (* means unbounded). Group is the content model the child belongs to: sequence children must appear in the order listed, choice children are alternatives.

    The schema is the contract for files DesignBuilder accepts; to check a file or a loaded model against it, use dsbxml.utils.validate_against_xsd.
