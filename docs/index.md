# DesignBuilder Schema

Welcome to the DesignBuilder Schema documentation. This site provides automatically generated API reference documentation for all Pydantic models.

## Quick Start

```bash
pip install designbuilder_schema
```

## Features

- **Type-safe models** using Pydantic
- **Auto-generated documentation** from docstrings
- **Complete API reference** of all schema models
